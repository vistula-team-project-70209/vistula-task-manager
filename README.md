
# Task Manager

**Student ID:** 70209  
**University:** Vistula University  
**Course:** Team Project – IT

## Project Description

This project is a web-based Task Manager application developed using HTML, CSS, JavaScript, and Supabase.

The application allows users to create, view, edit, complete, and delete tasks. All tasks are stored in a Supabase PostgreSQL database and remain available after refreshing the page.

## Live Application

https://vistula-team-project-70209.github.io/vistula-task-manager/

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase PostgreSQL
- Supabase JavaScript Client
- GitHub Pages

## Features

- Create new tasks
- View existing tasks
- Edit task titles and descriptions
- Mark tasks as completed or incomplete
- Delete tasks
- Store tasks in a persistent database
- Display error and status messages
- Responsive user interface

## Project Files

- `index.html` – Application structure
- `style.css` – Application styling
- `app.js` – Task management and database operations
- `config.json` – Supabase configuration
- `README.md` – Project documentation

## Database

The application uses a Supabase PostgreSQL table named `tasks`.

Database columns:

- `id` – Unique task identifier
- `title` – Task title
- `description` – Optional task description
- `completed` – Task completion status
